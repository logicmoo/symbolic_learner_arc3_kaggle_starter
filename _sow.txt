Image Perception to Recognizable Memory 
This Statement of Work (“SOW”) is entered into under the Master Services Agreement above. It defines three deliverable-based 
phases. The total fixed price for all phases is $20,000 USD.

Phase 1 — Grid Infrastructure and ARC3 Debugger Foundation 
• Adapt the existing ARC debugger workflow to the ARC3 environment. 
• Load and interact with selected ARC3 games and levels. 
• Capture game states, actions, observations, and execution history. 
• Store explored states in a GitHub-browsable action tree. 
• Generate structured artifacts describing states, objects, differences, similarities, reconstructions, and candidate rules. 
• Maintain stable and human-readable object identities across state transitions. 
• Support replay, reset, restart, and navigation through previously captured states. 
• Provide combined analysis of the current state and its transition from the previous state. 
• Cache generated artifacts for repeatable inspection and reuse. 
• Establish the initial grid infrastructure for object extraction, correspondence, transformation analysis, and rule inspection. 
• Provide documentation covering the debugger architecture, state trees, symbolic artifacts, and evidence records. 
Delivery 3 weeks 
Price $4,000 USD 
Phase 2 — Object Perception, Recognition, and Persistent Memory 
• Extract and represent objects from grid, image, and simple video inputs. 
• Represent object properties, structure, relationships, position, orientation, scale, and appearance. 
• Maintain stable object identities across examples, encounters, and state transitions. 
• Match corresponding objects between states and across repeated encounters. 
• Recognize recurring objects despite supported changes in position, orientation, scale, reflection, color, noise, or partial 
visibility. 
• Detect object movement, recoloring, resizing, addition, removal, and structural change. 
• Store objects in a normalized form from which they can be regenerated. 
• Distinguish recognized content from potentially new object structure. 
• Prevent duplicate storage of objects that have already been recognized. 
• Accumulate evidence and provenance across repeated encounters. 
• Preserve encounter history and support deterministic replay. 
• Provide persistent symbolic memory for recognized objects, observations, and associated artifacts. 
• Demonstrate object regeneration from stored representations. 
• Demonstrate recognition under modest degradation and partial occlusion. 
• Provide tests and documentation covering object identity, recognition, regeneration, memory, and replay. 
Demonstration workflow: 
Input image or game state  →  Object extraction  →  Object representation  →  Object matching and correspondence  →  Before-
and-after state comparison  →  Persistent storage  →  Later recognition as the same object 
Delivery 1 month 
Price $8,000 USD

Phase 3 — Game Object Learner Integration and Predictive Rule Learning 
• Define the interface and data contract connecting the object-perception and memory layer to the Game Object Learner. 
• Provide detected objects, properties, relationships, correspondences, state differences, and encounter history to the game-
learning system. 
• Provide a stable interface that does not require the Game Object Learner to depend directly on debugger or perception-layer 
internals. 
• Add interface validation, structured errors, integration tests, and example workflows. 
• Infer candidate object-level transformations and transition rules from observed examples. 
• Support multiple candidate interpretations and retain evidence for successful and unsuccessful rules. 
• Apply learned object-level transformations to new cases. 
• Predict later states before their outcomes are observed. 
• Compare predictions with independently observed outcomes. 
• Update rule evidence based on prediction success or failure. 
• Prevent post-hoc explanations from being treated as successful predictions. 
• Demonstrate recognition and completion of partly occluded objects. 
• Demonstrate operation across the approved grid and raster test environments. 
• Provide integration documentation, example scripts, acceptance-test results, and developer notes. 
Demonstration workflow: 
Input game state  →  Object perception and recognition  →  Persistent object identity  →  Structured handoff to the Game 
Object Learner  →  State-transition analysis  →  Candidate transformation learning  →  Prediction of a later state  →  Application 
to a new case  →  Evaluation of the prediction  →  Resulting prediction, learned rule, or action recommendation 
Representative environments: 
ARC-style grids  →  Rendered arcade environments  →  Fixed-camera physics examples  →  Top-down manipulation with 
partial occlusion 
Delivery 1 month 
Price $8,000 USD
